# Лабораторная работа №2

Разработка динамической библиотеки операций над массивами на C++.

## Возможности библиотеки

- Сумма элементов массива
- Максимальный и минимальный элементы
- Среднее арифметическое
- Подсчёт положительных, отрицательных и нулевых элементов
- Произведение элементов
- Медиана массива

## Сборка

cmake -S . -B build

cmake --build build

## Тестирование

ctest --test-dir build --output-on-failure

## Вариант 3 — Продажи магазина

Программа вычисляет общую, среднюю, максимальную, минимальную и медианную выручку магазина.

Запуск:

./build/variant_03
